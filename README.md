# Sheehan Ganguly Portfolio

A responsive, static portfolio website built with plain HTML, CSS, and JavaScript.

## Files
- `index.html` — site structure and content
- `styles.css` — responsive visual design
- `script.js` — mobile nav, scroll reveal, and project modal behavior
- `assets/Sheehan_Ganguly_Resume.pdf` — resume linked from the hero
- `assets/rta/` — RTA case-study images and report PDF

## Features
- Responsive landing page for your portfolio
- Featured project card for the RTA-V4 tapeout
- Clickable case-study modal with detailed project writeup
- Embedded project visuals including architecture, external-interface, and layout images
- Links to the full RTA report and layout image

## Preview locally
Open `index.html` directly in a browser, or run a local server from this folder:

```bash
python3 -m http.server 8000
```

Then visit `http://localhost:8000`.

## Deploy
This folder can be deployed as-is to GitHub Pages, Netlify, Vercel, or any static host.
